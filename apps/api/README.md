# @aria-erp/api

## Development

```bash
npm run start:dev
```

## Building

```bash
npm run build
npm run start:prod
```

## Testing

```bash
npm test
npm run test:e2e
```

## API Documentation

Swagger docs available at: `http://localhost:3001/api/docs`

## Architecture

- **Framework**: NestJS
- **Language**: TypeScript
- **Database**: PostgreSQL + Prisma
- **Caching**: Redis
- **Auth**: JWT
- **API Docs**: Swagger/OpenAPI
