**Three decisions the screen makes explicit, each pinned by a spec.**

1. **A refused page performs no reads at all.** The personnel-directory read is gated on
   `hr.leave.read` **and** `hr.employees.read`: without the leave grant the screen renders a refusal
   and every control those records serve is absent, so fetching a hundred personnel rows would be a
   tenant-wide read performed to render nothing. (This was the one real defect found while writing
   the specs — the directory read used to fire on a refused page — and
   `refuses the route without hr.leave.read, and reads nothing at all` now asserts all three reads
   are absent.)
2. **The catalogue is a precondition, not a convenience.** With an empty catalogue the request card
   states that nothing can be requested yet and offers no form; the catalogue card renders an empty
   list. No default taxonomy is carried anywhere, and the source-level assertion in the spec forbids
   bringing one back.
3. **The withdrawal is offered only while it is legal.** `CANCELLED` is terminal, so a second
   attempt is a guaranteed 409: the control is withdrawn rather than left on screen to fail, and the
   row shows the withdrawal INSTANT (rendered on the reader's clock) with the raw ISO kept in the
   DOM's `title`.

### 5.1 The one defect this phase found, and fixed

Writing the specs found the register issuing an unnecessary **tenant-wide personnel read on a page
that had already been refused**. `HrLeaveView` gates the directory effect on `hr.leave.read` **and**
`hr.employees.read` now: without the leave grant the screen renders a refusal and every control
those records serve is absent, so fetching a hundred personnel rows would be a read performed to
render nothing. `refuses the route without hr.leave.read, and reads nothing at all` asserts that all
three reads — register, catalogue and directory — are absent, which is what makes the fix a contract
rather than a hope.

`hr.e2e-spec.ts` — «holds the leave guarantees in PostgreSQL itself: composite keys, five CHECKs and
